# Mindspace Web

一个零依赖、可直接运行的思维导图 Web 原型。视觉采用接近 Codex 的低饱和深色工作区，数据使用清晰的 JSON 格式，便于人工或 Codex 直接理解和编辑。

## 运行

直接双击 `index.html`，或在本目录启动自带的零依赖静态服务器：

```powershell
node server.js
```

然后访问 `http://127.0.0.1:4173/`。

## 已实现

- 左侧栏目可显示/隐藏：工具、工程、文档、大纲、设置
- 点击节点打开右侧 Inspector
- Inspector 可编辑标题、备注说明、自定义 AI 合约文本、颜色、结构、优先级和节点尺寸
- 左侧“合约”页面支持按类目增删查改可复用合约；合约包含全局唯一标题、颜色和 Prompt 内容
- 节点可引用多个合约，并以彩色胶囊显示；移除引用不会删除合约库中的原始合约
- 有备注的节点在右上角显示角标，悬停或聚焦时显示备注气泡
- 点击连线打开专属 Inspector，可编辑标题、备注、颜色、线型和箭头
- 连线标题显示在线路中部，备注可悬停查看；删除连线不会改变节点属性或父子关系
- 从节点上、右、下、左四个连接点拖到其他节点，可创建独立关系连线
- 选中连线后可拖动两端端点到其他节点，重新连接并自动吸附上、右、下、左边缘
- 连线可配置无箭头、终点箭头、起点箭头或双向箭头
- 选中连线后可按 `Delete` 或 `Backspace` 删除
- 拖动节点右下角手柄自由调整大小，双击手柄恢复自适应
- 节点拖动、画布平移、滚轮缩放和适应视图
- 空白区域拖动框选多个节点，支持成组拖动和批量删除
- 鼠标中键拖动或 `Space + 拖动`平移画布
- 添加、复制、删除节点；支持撤销和重做
- 浏览器本地自动保存
- 新建空白工程、打开和保存 `.mindspace.json` 工程文件
- 支持“保存”“另存为”和最近工程本地快照
- 快捷键：`Ctrl+N` 新建、`Ctrl+O` 打开、`Ctrl+S` 保存、`Ctrl+Shift+S` 另存为
- 常用快捷键：`Ctrl+B`、`Ctrl+Z`、`Tab`、`Delete`、`Ctrl+D`

## 数据格式

工程文件使用版本 3 JSON 格式，由 `canvases`、`contractCategories` 和 `contracts` 等字段组成。每个节点通过 `parentId` 表示父子关系，通过 `contractIds` 引用工程合约，并使用 `aiPrompt` 保存节点独有的自定义合约文本。因此可以直接修改 JSON，无需解析二进制格式；旧版工程会在打开时自动升级。
